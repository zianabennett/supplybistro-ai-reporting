# Business context and named examples

[Project overview](../README.md) · [Method and data](method.md) · [Generated results](../results/summary.md)

**Named business examples; fictional records.** This independent portfolio demonstration uses real public business names as labels for an invented purchasing model. All 72 purchase orders, amounts, dates, overdue balances, and delivery metrics are synthetic. None represents the named businesses' actual finances or performance.

## How the names are used in this project

The technical fields `supplier_id` and `supplier_label` remain unchanged. Each public name occupies a supplier slot in the fictional model. The IDs SUP-A through SUP-D are portfolio identifiers, not business account IDs supplied by these organizations. The assignment does not document actual buyer-supplier relationships or any purchasing activity involving the named businesses.

The labels replace Supplier Alpha, Supplier Beta, Supplier Gamma, and Supplier Delta, respectively. The 72 order records and all calculations are unchanged. A displayed overdue order or delivery percentage belongs only to the invented fixture. It must not be read as a claim about a business's reliability, spending, revenue, savings, or financial impact.
